# Расписание ФКН — Android-приложение с виджетами

Неофициальное Android-приложение расписания 3 курса ФКН. Данные берутся с
[raspisanie.artefamily.online](https://raspisanie.artefamily.online) — тот же
источник, что и сайт. Приложение, виджеты и уведомления работают офлайн
(после первой загрузки).

## Возможности

- 📅 **Расписание недели** — числитель/знаменатель переключаются автоматически
  по ISO-неделям (как на сайте), выбор запоминается до конца недели
- 🧩 **Виджет «Сегодня»** — ближайшая пара прямо на рабочем столе
- ⏱ **Виджет-таймер** — крупный отсчёт «сколько до начала пары»
- 🔔 **Уведомления** — напоминание за 10/15/30/60 минут до пары
- 🌙 Тёмная тема, «окна» между парами, метка «сейчас», дистанционные пары (ДО)
- 📴 Полный офлайн: данные хранятся локально, фоновая синхронизация раз в 6 часов

## Установка

Скачайте APK из [Releases](../../releases) и откройте на телефоне
(потребуется разрешить установку из неизвестных источников — код открыт,
собрать можно самому, см. ниже).

## Сборка из исходников

Требуется JDK 17 и Android SDK (platform 34, build-tools 34).

```
git clone https://github.com/Magius2/fkn-raspisanie
cd fkn-raspisanie
gradle assembleRelease   # или откройте проект в Android Studio
```

APK появится в `app/build/outputs/apk/release/`.

Подпись релизных APK описана в CI (`.github/workflows/build.yml`).

## Приватность

Приложение:
- обращается **только** к `raspisanie.artefamily.online` (данные расписания);
- не собирает и не отправляет никакие пользовательские данные — ни аналитики,
  ни трекеров, ни идентификаторов;
- хранит локально только выбранную группу и копию расписания.

## Структура

```
app/src/main/java/store/artefamily/fknschedule/
├── MainActivity.kt        — главный экран
├── DayAdapter.kt          — список дней и пар
├── model/Model.kt         — JSON-модель data.json / cal.json
├── logic/ScheduleLogic.kt — недели числ/знам, окна, «следующая пара»
├── sync/                  — загрузка, хранилище, фоновая синхронизация
├── widget/                — виджет «Сегодня» и виджет-таймер
└── boot/BootReceiver.kt   — возобновление синхронизации после перезагрузки
```
